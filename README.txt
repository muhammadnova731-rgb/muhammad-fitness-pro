MUHAMMAD FITNESS PRO — бастаи веб-барномаи офлайнӣ

Муҳим:
- Ин файл APK нест; он веб-барномаи насбшаванда (PWA) аст.
- Барои он ки офлайн кор кунад, аввал онро як бор аз суроғаи HTTPS дар браузер кушоед.
- Баъд аз боркунии аввал, Service Worker файлҳои асосиро нигоҳ медорад ва барнома метавонад бе интернет кушода шавад.

Қадамҳои умумӣ аз телефон:
1. ZIP-ро кушоед ва файлҳоро ба як папка бароред.
2. Файлҳоро ба хостинги статикӣ, ки HTTPS медиҳад, ҷойгир кунед (масалан, GitHub Pages).
3. Суроғаи сайтро дар Chrome кушоед.
4. Менюи Chrome (се нуқта) → Add to Home screen / Добавить на главный экран.
5. Барномаро як бор бо интернет кушоед; баъд ҳолати офлайнро санҷед.

Маълумоти пешрафт дар хотираи браузери ҳамон телефон нигоҳ дошта мешавад.
Барои аз нав оғоз кардан тугмаи «Аз нав оғоз»-ро истифода баред.
Ин барнома маслиҳати тиббӣ нест. Машқҳоро бе маҷбуркунӣ иҷро кунед.
